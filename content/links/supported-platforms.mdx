## Copy-only platforms

Some entries aren't web addresses, so there's nothing to open. They're always added as **copyable text**: clicking them copies the value to the visitor's clipboard instead of opening a page.

* Riot ID
* PlayStation
* Nintendo Switch
* Bitcoin, Ethereum, Litecoin, Monero, Solana

<Aside type="tip">
  Any other platform can be turned into copyable text too, by picking *Copyable Text* instead of *Link* when you add it. See [Adding a Link](/links/adding-a-link/#link-types).
</Aside>
